# Kart Eşleştirme (Flutter)

## Proje adı

Kart Eşleştirme

## Proje amacı

Bu proje, klasik “Memory” mantığıyla çalışan **kart eşleştirme oyununu** Flutter ile geliştirir. Amaç; OOP prensiplerini (encapsulation, kalıtım/polimorfizm), modüler yapı tasarımını, hata yönetimini ve Git ile versiyonlamayı uygulamalı olarak göstermektir.

## Kurulum ve çalıştırma (demo)

Gereksinimler:

- Flutter (stable)
- Bir emulator veya fiziksel cihaz

Çalıştırma:

```bash
flutter pub get
flutter run
```

## Klasör yapısı (teslim formatı)

- `docs/`: Gereksinim analizi, UML diyagramları ve ek dokümanlar
- `Src/`: Uygulama kaynak kodları (models/, services/, ui/)
- `lib/`: Flutter entrypoint (Flutter import yapısı için `lib/Src` → `Src/` junction kullanılır)
